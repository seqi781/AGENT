# 14 能力天花板 vs 纪律天花板：两轮跑分把 7 道零分题看穿（v0.6.6 / v0.6.7）

这一章记录一个**负结果**——两轮针对性跑分都没把 7 道历史零分题翻过线。但负结果同样是结论：它把"我们的杠杆能撬动什么、撬不动什么"划清了。

## 背景：跑分纪律升级

用户授权我自主决策跑分，不再逐次请示，但立了一条纪律：**每次跑之前先落地一个修复，每次跑完必须能回答"这次解决了什么问题"**。本章是这条纪律下的头两轮实践。

## 第一轮 v066-7zeros：推理减负机制实战，分数仍 0/7

7 道题（caffe-cifar-10 / largest-eigenval / mteb-retrieve / path-tracing / path-tracing-reverse / password-recovery / winning-avg-corewars），flash，2.1 合规配置，7 路并发。结果 0/7，但失败的"质地"变了：

| 任务 | 死法 | 性质 |
|---|---|---|
| password-recovery | 密码找对了，写成 `PASSWORD=xxx`，测试要裸密码 | 格式一行之差 |
| largest-eigenval | 27 个速度桶过 25，差 2 个约 37% | 余量太薄 |
| winning-avg-corewars | 胜率 27%（要 75%） | 领域能力 |
| mteb-retrieve | 检索回 HumanEval 而非 MTEB 条目 | 包用法约定 |
| path-tracing-reverse | 图相似度 0.914（要 0.995） | 能力边界 |
| path-tracing | 编译都没过 | 能力不足 |
| caffe-cifar-10 | 40 轮耗尽，训练没跑完 | 时间不够 |

v0.6.6 机制确实在工作：E2 收尾快通道让多道题最后几轮降到 3.8s/轮；E1 撞顶抢救后**没有任何 trial 再以 reasoning_cap_loop 收场**；E4 触发 1 次。**推理浪费治住了，但分数没动——因为这些题的死因根本不是推理浪费。**

## 修复 v0.6.7：优化型任务协议

针对"余量太薄""没迭代到位"，给系统提示加了一节"Optimization tasks: beat the threshold WITH MARGIN"：复刻阅卷的度量方式、每次改进立刻写进交付文件、**过线不算赢（自测赢 5% 可能在更忙的机器上输 30%，要留 1.5 倍余量）**、变体台账避免重测。

## 第二轮 v067-timing3：单并发跑 3 道计时题，仍 0/3 —— 并纠正了一个错误假设

我原以为"7 路并发抢 CPU 压低了计时题成绩"，于是单并发重跑。结果证伪：

**关键认知**：largest-eigenval 的评分是候选解与参考解（`np.linalg.eig`）**在评分机上现场各测 100 次取中位数做相对比较**——机器负载被相对比较约掉了。单并发对它毫无帮助，它反而从 2 个失败变 7 个失败（纯运行间噪声）。计时型任务真正的难点是**过线余量要厚到噪声翻不动每个尺寸桶**。

flash 写的解是直接调 LAPACK `dgeev` 绕开 numpy 开销——思路完全正确，但对 2×2/4×4 这类最小矩阵余量不够（Python 调用开销占比太大），只过 20/27 桶。要真过得按尺寸分情况（2×2 用解析公式直接算，根本不调库）。**这是算法洞察，不是推理纪律问题。**

## 结论：分清两种天花板

- **纪律天花板**：模型有能力，但因推理浪费/不交付/不收摊/不达规范而丢分。这是 harness 和提示词能撬动的——M3、M4、v0.6.6、v0.6.7 都在打这层，把 20 题摸底从 0.5 推到 0.65。
- **能力天花板**：模型缺算法洞察或领域能力（写不出快过 LAPACK 的小矩阵解、写不出有竞争力的 Redcode、逆向不出渲染器到 0.995）。**这层 harness 撬不动**——再多提示词也变不出 flash 没有的智力。

7 道零分题除 password-recovery（格式，纪律层，可修）和 mteb-retrieve（约定，pro 能解）外，其余 5 道是实打实的能力天花板。

**战略转向**：停止打磨这 7 道。榜单分数住在另外 82 道我们有 headroom 的题里。下一步先做回归验证——确认 v0.6.6/v0.6.7 没有把已经通过的 13 道题弄退步（path-tracing-reverse 这轮从 0.914 退到颗粒无收，是个需要排查的警告信号）——再去那 82 道里找"差一点就过"的边际题，把杠杆用在撬得动的地方。

## 本章解决的问题

不是提分，而是**止损**：用两轮便宜的跑分（合计约 $0.35）确认了"继续磨最难的 7 道是低 ROI"，并把后续精力导向回归保护 + 边际题。负结果划清了能力边界，这本身就是决策依据。
