## 观察与结论

**好消息：**
- 框架全链路工作正常：循环、五个工具、轨迹日志、成本统计、实时进度打印。
- V4-Flash 的行为质量超预期：每步只做该做的事、修复前先复现、宣告完成前两次验证——系统提示的要求被完整遵守。
- 单轮延迟 1.2~6.9 秒，符合速度测试的预期。

**注意到的现象：**
- 输入 token（13,963）远大于输出（840）：对话历史每轮都要整体重发，输入随轮数线性增长——这就是为什么提示缓存（M3）对长任务的成本至关重要。
- 第 1 轮延迟 6.9s 明显高于后续（1~2s）：OpenRouter 路由 + 冷启动；正式评测固定 provider 后应该会更稳。

**一次通过不代表大功告成**：玩具任务远比 terminal-bench 简单（无交互程序、无复杂环境、任务明确无歧义）。真正的考验在 M2。
